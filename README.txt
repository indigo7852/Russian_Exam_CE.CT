РУССКИЙ ЯЗЫК — ПЛАТФОРМА

СТРУКТУРА
index.html       — страница сайта
css/style.css    — оформление
js/main.js      — интерфейс и логика страниц
js/database.js  — чтение настоящего Excel-файла
js/testing.js   — перемешивание заданий и подсчёт результатов
data/A1.xlsx    — ЕДИНСТВЕННЫЙ ИСТОЧНИК заданий А1

КАК ЗАПУСТИТЬ
1. Открой терминал в папке «Русский_язык_платформа».
2. Выполни: python3 -m http.server 8000
3. Открой в браузере: http://localhost:8000

ВАЖНО ПРО ДАННЫЕ
Слова и ответы не записаны в JavaScript. При запуске браузер загружает data/A1.xlsx, а js/database.js читает строки и формирует задания для интерфейса.
В проекте нет дублирующего файла a1-data.js, нет обращения к CDN и нет необходимости в интернете для загрузки парсера.
Чтобы изменить или дополнить задания, редактируй data/A1.xlsx, сохрани файл и обнови страницу (Ctrl+F5).

ТРЕБОВАНИЯ К ТАБЛИЦЕ
На листе должна быть строка заголовков со столбцами YEAR, EX, V, A(0)/O(1), TIPE, №, BOOL, WORD. Дополнительный столбец DIFF поддерживается.
Каждое новое задание начинается со строки, где заполнен V. У следующих строк этого задания V может быть пустым. В WORD записывается формулировка слова с пропуском и пометкой правильной буквы в конце, например «возр_стные изменения(А)». BOOL: 1 — А, 0 — О. TIPE: P, C или N.

ТЕХНИЧЕСКОЕ ПРИМЕЧАНИЕ
Для чтения XLSX используется встроенный в js/database.js компактный ZIP/XML-парсер на стандартных возможностях современного браузера. Нужен актуальный Chromium/Chrome/Firefox с поддержкой DecompressionStream. Сервер обязателен: не открывай index.html двойным щелчком.
