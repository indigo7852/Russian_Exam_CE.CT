РУССКИЙ ЯЗЫК — ПРОТОТИП ПЛАТФОРМЫ

СТРУКТУРА
index.html       — основная страница сайта
css/style.css    — стили исходного дизайна + интерфейс тестирования
js/main.js       — навигация, каталог, конструктор, тестирование, результаты
js/database.js  — чтение Excel и преобразование строк в задания
js/testing.js   — перемешивание и подсчёт баллов
data/A1.xlsx    — текущая база заданий А1

ЗАПУСК
Нельзя открывать index.html двойным щелчком: браузер блокирует fetch локального Excel.
Открой терминал в основной папке проекта и выполни:

  python -m http.server 8000

Затем открой в браузере:
  http://localhost:8000

ВАЖНО
Для чтения .xlsx библиотека SheetJS загружается с CDN, поэтому при первом запуске нужен интернет.
Исходная Excel-таблица не изменяется. Чтобы обновить базу, замени data/A1.xlsx новым файлом с тем же именем.

ТЕКУЩИЕ ОГРАНИЧЕНИЯ
- Сейчас база содержит тот набор строк, который был в переданном Excel.
- Встроенный перевод первичного в тестовый балл для неполного тренировочного теста является пропорциональным эквивалентом, а не официальным результатом ЦТ/ЦЭ.
- История попыток хранится локально в браузере (localStorage).
